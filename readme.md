## 📌 一、这个项目能告诉你什么

一句话核心结论（用 6 年真实数据回测得出）：

> 🎯 币圈不是“没有基本面”，而是“基本面 ≠ 财报”。情绪（恐惧贪婪指数）、流动性（稳定币占比）、估值位置（相对 200 日均线的偏离）这三个公开指标，对未来 30 天的收益存在可观测的关系——但它们更适合做**风险过滤器**，而不是**收益放大器**：极端贪婪时减仓、恐慌时加仓，能把最大回撤从 **-53%** 压到 **-46%**；但指望靠它跑赢“买入持有”，在趋势市里会失望。

更严谨的统计检验（V3 版）也如实写在仪表盘的“方法论”页里：

- ⚠️ 用严格口径（月度采样 + t 检验）验证后，三因子的 IC 显著性不足（|t| 均 < 2）
- 🔄 因子方向对“采样方式”高度敏感——单资产时序因子的方向稳定性，是这个课题最核心的不确定性
- ✅ 样本外唯一稳健的结论：**基本面风险过滤能显著改善回撤**

请把这份“诚实”当作本项目的最大价值——我们不粉饰数据，指标强弱、反直觉结果、统计局限全部透明展示。

## ⚙️ 四、环境准备（零基础版）

需要装一个 **Python**。

### 1️⃣ 安装 Python 3.9+

任选一种方式：

- 🌐 官网下载：https://www.python.org/downloads/ （Windows 安装时务必勾选 `Add Python to PATH`）
- 🍺 或通过包管理器：macOS 用 `brew install python`；Windows 用微软商店搜 Python

### 2️⃣ 安装依赖

打开终端（Windows 用 CMD 或 PowerShell；macOS 用“终端”App），执行：

```bash
pip install -r requirements.txt 
```
